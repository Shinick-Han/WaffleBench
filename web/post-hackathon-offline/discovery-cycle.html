Diagnostic discovery cycle

One recorded post-hoc diagnostic cycle: an Omnigent agent states a hypothesis, weighs competing catalog tests, picks one, and a deterministic runner measures it. The agent interprets each result and proposes the next experiment; the final prospective proposal remains unexecuted.
