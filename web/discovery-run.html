Scope and limitations
  • Each run is a fresh agent session over the same existing authored synthetic diagnostics. It is post-hoc and read-only, not a new hold-out gain, a factory result or a physical measurement.
  • The agent chooses tests and writes interpretations; a deterministic runner computes every number. Agent text is provisional, not a verified conclusion.
  • Verification confirms session completion and ledger/source integrity only. It says nothing about inspection accuracy or discovery speed.
  • A proposal first made at one update may be executed by the next plan; this is labelled. The final proposal of the cycle is not executed.
  • Runs are limited by the server (one at a time, with a quota and cooldown). The run identifier is kept only in this browser tab's session storage.
  • Fresh runs require the owner's PC, authenticated Claude session and tunnel to remain online. If unavailable, the verified recorded cycle remains accessible from the navigation above.
